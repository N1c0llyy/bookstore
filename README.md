# 📚 Bookstore

Projeto de uma aplicação backend para uma livraria, desenvolvido com **Python e Django**, com foco na construção de APIs REST e na aplicação de conceitos de desenvolvimento web.

## 🎯 Objetivo

Desenvolver uma aplicação para gerenciamento de livros, explorando funcionalidades e conceitos fundamentais do desenvolvimento backend.

## 🛠️ Tecnologias utilizadas

- Python
- Django
- Django REST Framework
- SQLite
- Docker

## 💻 Conceitos praticados

- Desenvolvimento de APIs REST;
- Gerenciamento de dados;
- Serialização de dados;
- Organização da estrutura de um projeto Django;
- Operações CRUD;
- Versionamento de código com Git e GitHub.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/N1c0llyy/bookstore.git
```

### 2. Acesse a pasta do projeto

```bash
cd bookstore
```

### 3. Crie um ambiente virtual

```bash
python -m venv venv
```

### 4. Ative o ambiente virtual

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 5. Instale as dependências

```bash
pip install django djangorestframework
```

### 6. Execute as migrações

```bash
python manage.py migrate
```

### 7. Inicie o servidor

```bash
python manage.py runserver
```

A aplicação estará disponível em:

http://127.0.0.1:8000/
